# Íconos Trazo de Insights

Todos los glifos Trazo del catálogo oficial de AXIS, exportados con `resolveIcon` de
`@efeoncepro/axis-graphic-line` desde Greenhouse: `pnpm insights:think-icons`. `trazo-<glifo>-dark.svg` va sobre
fondo oscuro (portada, 20 px) y `trazo-<glifo>.svg` sobre claro (tarjetas, 28 px). **Nunca se editan a mano**:
para cambiarlos, regenerarlos con ese comando. La portada recibe el glifo de cada alcance en
`header.scopeChips`; el mapa métrica → glifo de las tarjetas vive en `src/lib/insights-icons.ts`.
